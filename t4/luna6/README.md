# Brick Cab: Geneva Run

A self-contained arcade taxi game. Open `index.html` in a modern browser to play.

## Controls

- `W` / `↑`: accelerate
- `A` / `D` or `←` / `→`: steer
- `S` / `↓`: reverse or brake
- `Space`: handbrake drift
- `Shift`: boost
- `E` / `Enter`: pick up a passenger
- `R`: restart the shift

Touch controls appear on smaller screens. Drive to the amber passenger marker, pick up the fare, then follow the compass and mini-map to the next stop. The overview keeps every destination at the same map scale. The dispatch distance is the direct geodesic distance between the mapped coordinates; the street drawing is an arcade-style city map.

Landmark positions are based on OpenStreetMap data and credited in the game. OpenStreetMap data is available under the [Open Database License](https://www.openstreetmap.org/copyright).
