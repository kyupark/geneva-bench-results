Method

  • One run per model; outputs untouched apart from hosting path fixes. Card times are wall-clock. Models marked "resumed" were killed by a host restart at 23:45 on Oct 19 and finished in the same session; their first-run time is estimated from log timestamps.
  • Cost is listed only for API runs. Subscriptions (Grok CLI, Z.AI coding plan) have no per-run cost.
  • T2 ran with no human in the loop, so every prompt ended with the same line: "Don't ask questions, use your judgment and finish."
  • Reasoning effort is each model's maximum: xhigh for GPT, max for Claude.
  • Claude Opus ran on an API key, not a subscription. GLM 5.3 cannot see images, so GLM 5.3 Flash was attached as its eyes.
  • Every model got the same browser tool (headed Playwright).
  • Preview GIFs are ~10 s captures of the result page or clips from the model's own video. Videos over 25 MB can't be hosted, so the GIF stands in.
